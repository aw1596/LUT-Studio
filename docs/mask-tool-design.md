| 项目 | 内容 |

## 1. 产品概述与设计原则

### 1.1 定位与现状

LUT Studio 现有蒙版是「一个形状 + 一组独立调色」：新建径向、矩形、线性、画笔或钢笔选区，再在选区内调整参数。它足以处理单帧式的局部调整，但与视频工作流存在三个结构性缺口：

1. **选区没有时间延续**：镜头运动或主体移动后，蒙版停在原地，效果随之漂移。
2. **一个蒙版只能有一种形状**：无法把「AI 天空」与「线性渐变」组合成一个最终选区，也无法在不丢失参数的前提下改变选区构成。
3. **看不见整段素材上的有效范围**：用户不知道蒙版从第几秒到第几秒有效，更不知道哪一段跟踪已经失效。

本次改造把「蒙版」从**形状**升级为**选区容器**：蒙版 = 组合逻辑树 + 时间轨道 + 一组调色参数。现有五个形状全部保留，作为组合树中的原始选区节点；已有蒙版平滑迁移为「单节点组合树」，历史参数与画面效果不变。

### 1.2 目标用户与核心任务

| 项目 | 说明 |
| --- | --- |
| 主要用户 | 独立调色师、剪辑师、进阶摄影爱好者 |
| 触发场景 | 需要对画面局部（天空、人物皮肤、背景、特定颜色）做与全局不同的调整 |
| 核心任务 | 建立选区 → 在选区内调色 → 让效果在整段素材上稳定存在 → 随时检查与修正 |
| 完成条件 | 监视器上看到期望的局部效果，且在整段时间范围内可复现、可回溯、可修改 |

### 1.3 设计原则与视频含义

| 原则 | 产品含义 | 为什么这样适配视频 |
| --- | --- | --- |
| 蒙版是选区容器，不是滤镜 | 调色参数属于蒙版，不属于某个形状节点；增删节点、改组合逻辑都不影响已调参数 | 视频修改选区构成远比照片频繁，参数必须与选区解耦，否则每次调整都要重调 |
| 非破坏性 | 蒙版只定义选区与参数，不改写像素；删除蒙版不删除素材 | 视频素材不可重建，任何烘焙都应只发生在导出环节 |
| 组合运算优先 | 多个原始选区通过添加、减去、交叉、反转合成一个最终蒙版 | 视频主体的遮挡关系随时变化，单一形状无法覆盖 |
| 视频优先 | 每个蒙版拥有独立时间轨道，支持跟踪与关键帧；跟踪结果必须可检查、可修正 | 照片的选区一次生成即永恒，视频必须回答「这一秒选区在哪」 |
| 可视化优先 | 画面叠加显示 + 时间轴区间显示，两者颜色一致 | 用户必须同时回答「覆盖哪里」和「哪段时间有效」 |
| 性能透明 | 多蒙版共存时提示开销，提供整体开关、单蒙版禁用、折叠、简化预览 | 每增加一个蒙版，逐帧求值与跟踪都会增加成本，不能悄悄变卡 |

### 1.4 与 Lightroom 蒙版的对照

| 能力 | Lightroom 做法 | LUT Studio 决策 | 类型 |
| --- | --- | --- | --- |
| 蒙版结构 | 工具结果直接叠调整 | 工具结果作为节点进入组合树，调整挂在蒙版上 | 仿照 + 改造 |
| 创建工具 | 画笔、线性、径向、颜色范围、明亮度范围、主体/天空/背景/对象 | 全部保留，新增「深度范围」 | 仿照 + 新增 |
| 人物细分 | 面部皮肤、身体皮肤、眼睛、嘴唇、牙齿、头发、衣服 | 保留，并允许对细分结果再组合与跟踪 | 改造 |
| 组合方式 | 添加、减去、交叉 | 保留，并增加「反转」节点与可视逻辑树 | 仿照 + 改造 |
| 调整参数 | 亮度、颜色、效果、细节、光学 | 保留分组，并复用现有色轮 / 曲线 / HSL / 分离色调 / 校准控件 | 仿照 + 兼容 |
| 叠加显示 | 彩色、黑白、图像叠加于黑 | 保留三种，新增「其他蒙版弱化」与时间轴同色映射 | 改造 |
| 时间维度 | 无 | 独立轨道、关键帧、跟踪、有效/失效区间 | **新增** |
| 复制蒙版 | 可复制全部内容 | 复制时可选是否携带跟踪数据与关键帧 | 改造 |
| 区间外行为 | 不存在 | 明确定义「保持首/末帧」或「区间外禁用」 | **新增** |
| 失败处理 | 不存在 | 跟踪失效必须显式标记并提供修复入口 | **新增** |

## 2. 概念模型与信息架构

### 2.1 对象模型

| 对象 | 定义 | 关键属性 |
| --- | --- | --- |
| 蒙版 Mask | 选区容器，用户操作的最小单位 | 名称、颜色、启用、组合树、调整集、轨道、叠加设置 |
| 原始选区节点 SelectionNode | 组合树的叶子，一次工具操作的产物 | 工具类型、几何数据、工具参数、启停、是否随蒙版跟踪变换 |
| 组合运算 Operation | 连接节点或子树的关系 | 添加、减去、交叉、反转 |
| 时间轨道 Track | 蒙版在时间上的有效描述 | 有效区间、失效区间、跟踪数据、关键帧、跟踪状态 |
| 关键帧 Keyframe | 某一帧上的人工几何修正 | 帧号、完整几何（位置/大小/形状/羽化/旋转） |
| 调整集 AdjustmentSet | 作用于最终合成蒙版的一组调色参数 | 亮度、颜色、效果、细节、光学及现有高级组 |
| 叠加设置 Overlay | 蒙版在画面上的可视化方式，不参与渲染 | 叠加模式、颜色、是否始终显示 |

**共享定义（全文唯一口径）**

- **有效区间**：蒙版在时间轴上被认定为「跟踪可信、可渲染」的连续时间段。
- **失效区间**：跟踪置信度低于阈值，或用户标记为不可信的连续时间段。此区间内保留最后一帧可信几何（冻结），不自动插值。
- **空选区**：组合树在当前帧求值结果为空，或选区面积低于可感知阈值。
- **完全被减去**：某节点被后续「减去」运算完全抵消，最终结果为空。
- **区间外**：播放头位于有效区间之外。默认沿用首帧/末帧几何（保持），可在轨道菜单改为「区间外不渲染」。

### 2.2 信息架构

```
蒙版模块
├─ 蒙版列表
│  ├─ 新建蒙版入口（AI 智能选择 / 手动工具）
│  ├─ 每项：颜色点、名称、启停、类型摘要、跟踪状态、调整摘要
│  └─ 操作：重命名、排序、复制、删除、反转、叠加显示开关
├─ 蒙版详情（选中项展开）
│  ├─ 组合逻辑树（节点 + 运算 + 启停 + 重命名）
│  ├─ 当前节点工具参数（画笔 / 渐变 / 颜色范围 / 明亮度 / 深度）
│  └─ 轨道摘要（有效区间、失效段数、进入跟踪流程）
├─ 调整面板（始终作用于最终组合蒙版）
│  ├─ 亮度｜颜色｜效果｜细节｜光学
│  └─ 现有高级组：色轮、曲线、HSL、分离色调、校准
├─ 时间轴（蒙版轨道层）
│  ├─ 每条蒙版一条轨道：颜色、名称、有效区间、失效区间、关键帧
│  └─ 视图切换：跟踪数据 / 关键帧
└─ 叠加显示控制（预览台工具条 + 快捷键）
```

### 2.3 界面挂载与现有界面的关系

- **右侧属性面板**：现有「蒙版」折叠项扩展为「列表 → 详情 → 调整」三段；不新增第二个调色面板，避免同一参数出现两处入口。
- **预览台**：沿用现有蒙版画布与拖动交互；新增顶部叠加控制条（O 切换、颜色、始终显示）。
- **底部时间轴**：新增面板，占用现有底部素材条区上方，可拖动高度（复用现有面板尺寸拖拽能力）；素材胶片条与时间轴可折叠切换。
- **已有蒙版迁移**：五种形状各自成为一个叶子节点，原羽化、反转、参数原样保留；`反转` 升级为组合树上的反转运算，语义不变。

### 2.4 生命周期

```
新建（草稿） → 选择工具/生成选区 → 确认加入列表 → 组合调整
            → 调色参数 → 跟踪/关键帧 → 检查失效 → 导出（烘焙结果）
```

草稿态取消不写入撤销历史；确认后每个操作（节点、运算、参数、关键帧、跟踪区间修正）都进入撤销栈。

## 3. 蒙版创建工具清单及参数说明

### 3.1 AI 智能选择

一键在当前帧生成基础选区，生成后仍需用户确认与微调，不直接生效。

| 目标 | 细分 | 说明 |
| --- | --- | --- |
| 主体 | — | 画面中最显著的被摄对象 |
| 天空 | — | 天空区域，含云层边界 |
| 背景 | — | 主体之外的环境 |
| 对象 | — | 框选或点击指定物体后分割 |
| 人物 | 面部皮肤、身体皮肤、眼睛、嘴唇、牙齿、头发、衣服 | 可整体生成，也可只选某个细分部位 |
| 风景 | 天空、山脉、植被、水、自然地面、人造地面 | 多类可同时返回，按类生成节点 |

**参数**：羽化（0–100）、边缘（-100–100，收窄/扩张 1–5 像素量级的过渡带）、「生成后自动跟踪」（默认关闭）。

**视频适配**：AI 结果只在**当前帧**生成，作为静态选区节点；勾选自动跟踪后，立即进入 5.2 的跟踪流程并生成轨道数据。这样避免用户误以为「AI 生成即全片有效」，同时保留一键化路径。

**边界**：分割失败或无置信结果时，提示「未识别到目标，请换一帧或改用手动工具」，不产生空节点。

### 3.2 画笔

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 大小 | 1–100 | 笔刷直径，按画面短边百分比 |
| 羽化 | 0–100 | 笔刷边缘柔化 |
| 流畅度 | 0–100 | 描边平滑程度 |
| 密度 | 0–100 | 单次描边的覆盖强度 |
| 自动蒙版 | 开/关 | 将描边限制在颜色相近区域，减少越界 |
| 擦除模式 | 开/关 | 从当前节点中擦除已绘制区域 |

**视频适配**：描边以画面归一化坐标存储，不属于某一帧；默认在整段素材生效。蒙版启用跟踪时，描边随蒙版变换整体移动；节点可单独关闭「随跟踪变换」以保持静态。

**边界**：擦除至空时提示「该画笔选区已为空」，节点保留但暂停参与合成。

### 3.3 线性渐变

拖拽方向线定义过渡：位置、角度、过渡范围（两条参考线间距）、羽化。适用于天空、地平线等大范围柔和过渡。视频中默认为静态几何，可由蒙版跟踪整体带动。

### 3.4 径向渐变

椭圆/圆形选区：中心位置、大小、长宽比、旋转、羽化。适用于主体提亮、暗角、局部光效。拖动中心可移动，拖动手柄可缩放与旋转；数值面板可精确输入。

### 3.5 颜色范围

吸管在画面取样，`Shift` 加选，最多 5 个样本；提供「优化」滑块（-100–100）收窄或扩大色相/饱和度范围。视频适配：取样基于当前帧，默认生成静态颜色判据（按像素颜色判断，因此天然随时间有效）；若目标颜色随光线变化，可改用跟踪后的局部选区。

### 3.6 明亮度范围

在画面点选亮度基准，自动选中该亮度区间；提供范围宽度与平滑过渡。适合分离高光/阴影。视频适配：逐帧按亮度判断，不需要跟踪，但光线剧烈变化时结果会变化，界面需提示「随帧亮度变化」。

### 3.7 深度范围（条件支持）

若素材带深度信息，按前景/背景建立选区：近端距离、远端距离、过渡宽度。无深度信息时工具置灰，提示「当前素材无深度信息」，不自动降级为其他工具。

### 3.8 工具选择建议

| 场景 | 推荐工具 | 原因 |
| --- | --- | --- |
| 天空调色 | AI 天空 + 线性渐变 | AI 贴合轮廓，线性控制过渡与范围 |
| 人物提亮 | AI 主体 + 径向渐变 | 主体保证不漏背景，径向塑造光感 |
| 肤色校正 | 人物皮肤 / 颜色范围 | 语义选区比颜色选区更稳 |
| 背景压暗 | AI 背景 + 反转 | 背景边界由语义保证 |
| 特定道具 | 对象 + 画笔修边 | 先用语义大范围，再手工修补 |
| 前景/背景分离 | 深度范围 | 依赖深度信息，最省人工 |

## 4. 组合运算与逻辑树交互

### 4.1 运算语义

| 运算 | 语义 | 结果 |
| --- | --- | --- |
| 添加 | 并集 | A ∪ B |
| 减去 | 差集 | A − B |
| 交叉 | 交集 | A ∩ B |
| 反转 | 补集 | 对**其子树输出**取反，而非单节点 |

**求值规则**：按树的视觉顺序（自上而下）深度优先求值；每个连接符作用于「上方累计结果」与「下方子树结果」；反转只影响其子树；最终输出即合成蒙版。求值逐帧执行，与调整参数无关。

**空结果规则**：任一中间结果为空不报错，继续求值；最终结果为空时，蒙版进入「空选区」状态，参数保留但不渲染。

### 4.2 逻辑树界面

每个节点是一张卡片：工具图标、自动命名（可重命名）、几何摘要（如「天空 · 羽化 20」）、启停开关、更多菜单（复制 / 删除 / 反转）。

连接符为可点击的胶囊：`＋ 添加`、`− 减去`、`∩ 交叉`，点击展开下拉即可改运算；拖动卡片可重排顺序；树底部固定「＋ 添加选区」入口。

节点命名默认按工具 + 序号（「天空 1」「径向 2」），重命名即时反映到节点卡片与轨道标签。

### 4.3 参数保持与即时刷新

修改运算、增删节点、调整节点顺序、启停节点时：

- 蒙版调整集、轨道数据、关键帧**全部保留**；
- 当前帧合成结果即时重算并刷新预览；
- 每次结构变化写入一条撤销记录（可整体撤销）。

**为什么适配视频**：视频调色常需反复试探选区构成，若改结构就丢参数，等于惩罚探索；因此结构操作必须是低成本、可逆的。

### 4.4 视频维度的选区与跟踪归属

- 默认采用**蒙版级跟踪**：一个蒙版一条轨道，跟踪变换作用于所有节点几何，心智与 Lightroom 的「一个蒙版一套调整」一致。
- 每个节点提供「随跟踪变换」开关；关闭后该节点保持画面固定（如固定位置的渐变）。
- 节点级独立跟踪为 P1 能力：轨道展开为子轨，适合「天空固定 + 人物移动」等混合场景；本期先保证蒙版级跟踪的正确性与可修正性。

### 4.5 典型组合

1. **天空去灰**：`天空(AI) ∩ 线性渐变` → 只压天空上部，避免压暗远山。
2. **主体提亮避高光**：`主体(AI) − 径向渐变(高光区)` → 主体提亮但保留高光。
3. **保护肤色**：`颜色范围(肤色) → 反转` → 除肤色外整体降饱和。
4. **衣服去色**：`人物(AI) ∩ 衣服细分` → 只对衣服做饱和度调整。

## 5. 视频跟踪与关键帧交互流程

### 5.1 轨道与区间可视化

每条蒙版轨道包含：颜色点与名称、启停眼睛、有效区间条（蒙版色）、失效区间（红色斜纹）、关键帧菱形、播放头。轨道宽度与素材时长对齐，缩放随主时间轴；轨道高度紧凑，选中后展开显示「跟踪数据 / 关键帧」视图切换与失效入口。

区间外采用斜纹弱化显示，并在轨道菜单提供「保持首/末帧」与「区间外不渲染」两种行为。

### 5.2 跟踪模式选择

| 模式 | 适用目标 | 不适用 |
| --- | --- | --- |
| 点跟踪 | 纹理清晰、面积较小的目标；平移为主 | 大面积旋转、透视变化 |
| 平面跟踪 | 墙面、屏幕、地面等平面；透视与旋转 | 非平面物体、强形变 |
| 人脸跟踪 | 人物面部与五官细分 | 侧脸、遮挡严重时需人工修正 |
| 物体跟踪 | 语义明确的产品、道具、动物 | 低对比、快速出画 |

界面提供一段简短对照说明；默认按工具结果推荐（AI 主体 → 物体跟踪，人物细分 → 人脸跟踪）。

### 5.3 标准跟踪流程（界面引导，不可跳步）

1. **选择跟踪方式**：轨道工具条「跟踪」→ 选择模式。
2. **确认跟踪窗口**：在画面上框选目标；系统默认外扩目标尺寸 5%–10% 作为余量，边缘柔化，避免边界抖动。
3. **选择方向与范围**：从当前帧向前 / 向后 / 双向，到片段末尾或指定帧。
4. **分析**：显示进度与「取消」；取消保留已完成区间。
5. **逐帧检查**：分析结束自动跳到第一段失效起点，并高亮该区间；用户可播放检查。
6. **修正或确认**：修正此区间 / 重新跟踪 / 手动关键帧；确认后写入轨道与撤销记录。

### 5.4 失效处理

- 置信度低于阈值即判为失效，**不自动插值、不静默跳到错误位置**；该区间冻结最后一帧可信几何。
- 画面叠加与轨道同步显示警告；蒙版列表显示「2 段失效」徽标。
- 三个修复入口：
  - **修正此区间**：进入区间编辑，起点/终点自动插入关键帧，用户逐帧微调；
  - **重新跟踪**：从指定帧重跑跟踪，可替换当前区间的数据；
  - **手动关键帧**：在失效段内插入关键帧，人工覆盖跟踪结果。
- 全部失效段修正后，状态回到「有效」。

### 5.5 关键帧编辑

- 播放头处插入关键帧；轨道上拖动改时间；右键删除。
- 关键帧记录**完整几何**（位置、大小、形状、羽化、旋转），避免不同属性间时间不同步。
- 帧间默认平滑插值；区间两端默认保持（不外推）。
- 连续逐帧微调时，可开启「吸附到跟踪数据」，避免与已有跟踪结果冲突。
- 关键帧与跟踪数据共存时，关键帧优先。

### 5.6 两种视图

| 视图 | 显示 | 用途 |
| --- | --- | --- |
| 跟踪数据 | 密集采样带 + 失效段 | 快速检查整段稳定性 |
| 关键帧 | 仅菱形标记 | 精细控制与逐帧修正 |

两视图读取同一份时间数据，切换不改变任何结果。

### 5.7 状态机

| 状态 | 进入条件 | 界面表现 | 可用操作 |
| --- | --- | --- | --- |
| 未跟踪 | 新建蒙版 / 清空轨道 | 轨道仅一条静态条 | 跟踪、手动关键帧 |
| 分析中 | 开始跟踪 | 进度条、取消 | 取消 |
| 有效 | 跟踪完成且无失效段 | 正常区间条 | 检查、重跟踪、删除数据 |
| 部分失效 | 存在失效区间 | 红色斜纹 + 徽标 | 修正、重跟踪、手动关键帧 |
| 失效 | 整段不可信 | 整条红色斜纹 | 重跟踪、手动关键帧 |
| 手动 | 全部由关键帧定义 | 菱形标记 | 插入/删除关键帧 |

## 6. 蒙版内调整参数表

所有参数始终作用于**最终组合蒙版**，与选区构成、跟踪状态解耦。

| 组 | 参数 | 范围 | 视频注意事项 |
| --- | --- | --- | --- |
| 亮度 | 曝光度 | -5 ~ +5 EV | 局部曝光变化会放大跟踪误差，建议配合柔边 |
| 亮度 | 对比度 | -100 ~ +100 | — |
| 亮度 | 高光 / 阴影 | -100 ~ +100 | 逐帧亮度变化时可能闪烁，可降低幅度 |
| 亮度 | 白色色阶 / 黑色色阶 | -100 ~ +100 | 与高光/阴影叠加时注意裁切 |
| 颜色 | 色温 / 色调 | -100 ~ +100 | 参考帧取样，跨镜头需重新确认 |
| 颜色 | 饱和度 / 色相 | -100 ~ +100 | 视频中建议小幅调整以保证连续性 |
| 颜色 | 点颜色（Point Color） | 最多 5 个取样点 | 对选区内特定色相独立偏移；取样基于帧，光线变化需复核 |
| 效果 | 纹理 | -100 ~ +100 | 视频默认强度低于照片，避免帧间噪点被放大 |
| 效果 | 清晰度 | -100 ~ +100 | 高对比边缘易出现帧间闪烁，建议 ≤30 |
| 效果 | 去朦胧 | -100 ~ +100 | 大范围使用时关注暗部噪点 |
| 细节 | 锐化 | 0 ~ 150 | 逐帧锐化差异会造成「呼吸」，建议开启时域稳定（P1） |
| 细节 | 杂色减少 | 0 ~ 100 | 视频噪点随时间变化，强度过高会抹除细节 |
| 光学 | 摩尔纹消除 | 0 ~ 100 | 仅对有摩尔纹的素材开启 |
| 光学 | 去边 | 0 ~ 100 | 高对比边缘处使用 |

**现有控件保留**：色轮（暗部/中间调/高光）、RGB 曲线、HSL、分离色调、校准继续作为同一调整集的高级组，与上表并列折叠，不改变现有交互。

**参数操作**

| 操作 | 规则 |
| --- | --- |
| 分组折叠 | 每组独立折叠，折叠不改变取值 |
| 重置 | 组内重置 / 全部重置，均可撤销 |
| 复制到其他蒙版 | 选择目标蒙版，复制全部参数；可选是否同时复制选区与轨道 |
| 临时对比 | 按住 `\` 临时禁用当前蒙版渲染，松开恢复；也可用眼睛开关做持久禁用 |

**为什么参数放在蒙版级**：视频中选区结构会频繁变化，参数必须跟着「这块区域」而不是「这个形状」；同时与 Lightroom 的心智一致，降低学习成本。

## 7. 可视化与快捷键

### 7.1 叠加模式

| 模式 | 表现 | 用途 |
| --- | --- | --- |
| 彩色叠加（默认） | 选区填半透明蒙版色 | 日常建立与检查选区 |

| 图像叠加于黑 | 仅选区显示画面，其余压黑 | 检查选区是否漏选/多选 |
| 关闭 | 不显示叠加 | 纯效果预览 |

### 7.2 颜色与时间轴对应

- 调色板 8 色；新建蒙版自动分配未使用颜色。
- 轨道、蒙版列表色点、画面叠加色三处保持同一颜色。
- 当前编辑蒙版 100% 不透明度；其他蒙版 30%，交叉区域用斜纹提示重叠。
- 叠加显示可全局关闭，但时间轴颜色始终保留。

### 7.3 快捷键

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `O` | 切换叠加显示开/关 | 与 Lightroom 一致 |
| `Shift + O` | 循环切换叠加模式与颜色 | 与 Lightroom 一致 |
| `M` | 新建蒙版 | 默认沿用上次工具 |
| `Ctrl/Cmd + D` | 复制当前蒙版 | 弹出复制选项 |
| `Delete` | 删除当前蒙版 | 可撤销 |
| `[` / `]` | 上一个 / 下一个蒙版 | 快速切换 |

| `Shift + I` | 删除当前帧关键帧 | — |
| `,` / `.` | 跳到上 / 下一个关键帧 | 与逐帧微调配合 |

| `Space` | 播放 / 暂停 | 沿用现有播放器 |

### 7.4 性能透明

- 蒙版数量 ≥ 4 时，蒙版面板顶部显示「N 个蒙版 · 预览开销较高」提示。
- 提供三个降级开关：仅显示当前蒙版叠加、简化预览（半分辨率 / 关闭叠加）、单蒙版禁用。
- 跟踪分析期间暂停实时调色预览，避免双负载。

## 8. 状态与异常边界

### 8.1 三级控制

| 层级 | 控制对象 | 行为 |
| --- | --- | --- |
| 整体 | 全部蒙版 | 一键关闭所有蒙版渲染，参数保留 |
| 单蒙版 | 一个蒙版 | 眼睛开关，暂停该蒙版合成 |
| 节点 | 组合树叶子 | 暂停该节点参与合成，立即刷新结果 |

### 8.2 蒙版状态

| 状态 | 判定 | 界面 |
| --- | --- | --- |
| 草稿 | 已新建未确认 | 节点虚线边框，可取消 |
| 启用 | 正常渲染 | 正常 |
| 禁用 | 眼睛关闭 | 列表与轨道降低不透明度 |
| 空选区 | 当帧合成结果为空 | 黄色警告「蒙版为空，调整不生效」 |
| 完全被减去 | 节点被后续运算完全抵消 | 节点红色标记 + 提示 |
| 已删除 | 删除后 | 从列表与轨道移除，可撤销恢复 |

### 8.3 异常与恢复

| 场景 | 表现 | 提示 | 恢复入口 |
| --- | --- | --- | --- |
| 选区为空 | 调整无效果 | 「蒙版为空」 | 改工具/补节点/恢复节点 |
| 组合结果为空 | 画面无变化 | 顶部警告条 | 检查减去/交叉节点 |
| 跟踪丢失 | 冻结几何 + 红纹 | 轨道徽标「2 段失效」 | 修正此区间 / 重跟踪 / 手动关键帧 |
| 跟踪分析失败 | 无轨道数据 | 「分析失败，未生成数据」 | 重试 / 换模式 / 手动关键帧 |
| 深度信息缺失 | 工具置灰 | 「当前素材无深度信息」 | 换工具 |
| 素材被外部修改 | 蒙版仍指向原路径 | 加载失败提示 | 重新导入；蒙版数据保留 |
| 多蒙版卡顿 | 预览下降 | 「预览开销较高」 | 简化预览 / 禁用蒙版 |

### 8.4 撤销 / 重做覆盖

创建蒙版、确认/取消草稿、增删节点、修改运算、重命名、排序、节点启停、参数调整与重置、复制粘贴、关键帧插入/删除/移动、跟踪区间修正、删除蒙版，均进入撤销栈。播放与叠加显示切换不进入。

### 8.5 复制 / 粘贴

复制蒙版时可选携带：调整参数（默认勾选）、选区节点（默认勾选）、跟踪数据与关键帧（默认**不**勾选，因目标时间区间可能不同）。粘贴到当前片段，若携带关键帧则整体平移到当前播放头。

### 8.6 非破坏性保证

- 蒙版、节点、轨道均为独立描述数据，不写回素材。
- 删除蒙版、删除节点不影响原始像素。
- 仅在导出时把结果烘焙到输出文件，原素材保持不变。
- 导出时可选择是否包含蒙版效果，便于 A/B 对比。

### 10.2 三条关键交互

1. **新建 → 调整**：点「＋ 新建蒙版」→ 选「天空」→ 画面出现彩色叠加与羽化/边缘滑块 → 点「确认」加入列表 → 在同面板调整曝光，画面即时刷新。
2. **跟踪 → 修正**：轨道选中蒙版 → 「跟踪」→ 选模式 → 确认窗口（默认 5%–10% 余量）→ 分析完成自动跳到第一个失效段 → 「修正此区间」插入边界关键帧 → 拖动微调 → 状态回到有效。
3. **组合 → 参数保持**：在逻辑树中把「天空」连接符改为「交叉」并添加线性渐变 → 已调曝光不变，叠加显示即时收窄到交叉区域 → 撤销该结构操作可回到原组合。

### 10.3 迁移与兼容

- 现有五个形状全部保留为叶子工具，不新增学习成本。
- 已有蒙版自动转为「单节点 + 调色参数 + 静态区间」，用户可后续添加节点或跟踪。
- 现有高级调色组（色轮、曲线、HSL、分离色调、校准）在蒙版内继续可用。
